# Карта школьника — дашборд по школьному питанию Калининградской области

Интерактивная страница с двумя контурами. На входе — выбор контура.

- **Город Калининград** — ежедневные продажи 12 операторов питания в 43 школах, 02–14.09.2026. Обороты пересчитаны в транзакции по среднему чеку 150 ₽. Разделы: транзакции по дням, рейтинг операторов, таблица школ, матрица готовности по корпусам, проблемные зоны.
- **Калининградская область** — срез на 14.09.2026 по 113 школам, 21 муниципалитету и 7 КШП: привязка карт и ЛК родителей, готовность питания, оборудование и СКУД, рейтинг операторов, таблица школ, проблемные зоны.

`index.html` — автономная страница, все данные внутри файла, внешних зависимостей нет (шрифты подгружаются с Google Fonts, без них работает на системных).

Источники: выгрузка «Операторы питания» (город) и «Отчет Калининград 14.09.2026» (область).
