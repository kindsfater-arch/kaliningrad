# Дашборд: операторы школьного питания, Калининград

Интерактивный дашборд по данным ежедневного мониторинга за 2–11 сентября 2026.

- `index.html` — автономная страница, все данные внутри файла, внешних зависимостей нет.
- Разделы: обороты по дням, рейтинг операторов, таблица по 43 школам, матрица готовности по корпусам, проблемные зоны.
